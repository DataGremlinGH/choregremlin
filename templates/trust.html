Install On Your Device

iPhone or iPad

  1. Tap Download Trust Certificate, then allow the profile download.
  2. Open Settings → General → VPN & Device Management and install the Chore Gremlin profile.
  3. Open Settings → General → About → Certificate Trust Settings and turn on full trust for Chore Gremlin Local CA.
  4. Open {{ net.local_url }} and confirm the padlock appears.

Android

  1. Tap Download Trust Certificate.
  2. Open Settings → Security → Encryption & credentials → Install a certificate → CA certificate.
  3. Choose the downloaded choregremlin-root.crt file and install it.
  4. Open {{ net.local_url }} and confirm the padlock appears.

Windows or Mac

  1. Download the certificate and open it.
  2. Windows: choose Install Certificate → Local Machine → Place all certificates in the following store → Trusted Root Certification Authorities.
  3. Mac: add it to the System keychain and set it to Always Trust.
  4. Open {{ net.local_url }} and confirm the padlock appears.

Good To Know
  • The certificate only covers your home hub. Never install it on a device you do not control.
  • Use {{ net.local_url }} where possible; the IP address can change unless you reserve it in your router.
  • If you reinstall the hub, download and trust the new certificate.
